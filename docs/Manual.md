# Project Manual

## Purpose

This manual provides an overview of the Stellaro project, repository layout, and primary operational procedures for contributors and operators.

## Environments

- Production: app.stellaro.com and api.stellaro.com
- Staging: staging.stellaro.com
- Development: dev.stellaro.com

## Where to Start

- Read [DEV_ENVIRONMENT_SETUP.md](DEV_ENVIRONMENT_SETUP.md) to set up your local environment.
- See [DOCUMENTATION_INDEX.md](DOCUMENTATION_INDEX.md) for the canonical docs index.

## Contribution

- Follow the repository's contribution guidelines and branch workflow.
- Open PRs against `master` and include clear change descriptions and tests when appropriate.

## Contact

For operations and incident response contact the on-call platform engineer via the project's communication channels.
