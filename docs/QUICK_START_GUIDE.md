## 5️⃣ STEPS TO GET STARTED

### Step 1: Access Stellaro (2 minutes)

**Option A: Use the Website**
1. Visit: https://stellaro.io
2. Select your preferred language (EN or PT-BR)
3. Click "Get Started"

**Option B: Local Development**
```bash
# Clone repository
git clone https://github.com/jistriane/stellaro.git
cd stellaro

# Install dependencies
npm install

# Start local services
npm run dev

# Frontend: http://localhost:3000
# Backend: http://localhost:3001
```

### Step 2: Create Your Account (3 minutes)

1. Click **"Sign Up"** on the homepage
2. Enter your **email address**
3. Create a **strong password** (min 12 characters)
4. Enable **Multi-Factor Authentication (MFA)**
   - Scan QR code with authenticator app (Google Authenticator, Authy)
   - Save backup codes in secure location
5. Verify email (check inbox)
6. Click confirmation link
7. **Account created!** ✓

### Step 3: Connect Your Wallet (4 minutes)

Stellaro supports three wallet options:

**Option A: Freighter Wallet (Recommended)**
1. Install [Freighter Extension](https://www.freighter.app/)
2. Create or import Stellar account
3. In Stellaro app, click **"Connect Wallet"**
4. Select **"Freighter"**
5. Approve connection in wallet popup
6. **Wallet connected!** ✓

**Option B: Ledger Hardware Wallet**
1. Connect Ledger device to computer
2. Open Ledger Live app
3. In Stellaro, click **"Connect Wallet"**
4. Select **"Ledger"**
5. Approve on Ledger device
6. **Ledger connected!** ✓

**Option C: Albedo Wallet**
1. Visit [albedo.link](https://albedo.link) in new tab
2. Create or import account
3. In Stellaro, click **"Connect Wallet"**
4. Select **"Albedo"**
5. Approve in Albedo popup
6. **Albedo connected!** ✓

### Step 4: Fund Your Account (4 minutes)

You need XLM (Stellar Lumens) to start. Here's how:

**Option A: Buy on Exchange**
1. Create account on [Coinbase](https://coinbase.com) or [Kraken](https://kraken.com)
2. Buy 10-50 XLM (~$1.20-$6 USD)
3. Withdraw to your Stellar address:
   ```
   Your address: G... (from wallet)
   Network: Public (Stellar)
   Amount: 10-50 XLM
   ```
4. Wait 2-5 minutes for transfer
5. Check balance in Stellaro: Settings → Wallet → Balance

**Option B: Receive from Friend**
1. Get your Stellar address: Click wallet icon → "Copy Address"
2. Share with friend
3. Friend sends XLM to your address
4. Funds arrive in 5-10 minutes

**Option C: Bridge from Another Chain (Advanced)**
1. If you have crypto on other blockchains
2. Use bridge services: Stellar.org/bridges
3. Swap to XLM
4. Transfer to your Stellar wallet

### Step 5: Start Using Stellaro (2 minutes)

Once funded with XLM, you can:

✅ **Mint Stablecoin (STLT-BRL)**
- 1 XLM = 1 unit of backing
- Hold Brazilian Real stablecoin
- Use for payments, savings

✅ **Earn Interest**
- Lend stablecoins to earn 5-12% APY
- Join liquidity pools
- Participate in yield farming

✅ **Borrow**
- Borrow up to 80% of collateral
- Use for trading, leverage, emergencies

✅ **Trade**
- Swap XLM for STLT-BRL
- Trade with other users
- Use DeFi protocols

✅ **Vote on Governance**
- Participate in DAO decisions
- Propose new features
- Vote on protocol changes

## 📚 COMMON TASKS

### Task 1: Buy Stablecoin (STLT-BRL)

**Quick Steps** (2-3 minutes)

```
1. Dashboard → "Trading"
2. Select: Sell "XLM", Get "STLT-BRL"
3. Enter amount: e.g., "10 XLM"
4. Review rate (shown on screen)
5. Click "Confirm Swap"
6. Approve in your wallet
7. ✓ Done! Check balance
```

### Task 2: Join Lending Pool

**Quick Steps** (2-3 minutes)

```
1. Dashboard → "DeFi"
2. Click "Lending Pools"
3. Select pool with best APY (5-12%)
4. Click "Deposit"
5. Enter amount: e.g., "100 STLT"
6. Click "Confirm"
7. Approve in wallet
8. ✓ Done! Earning interest daily
```

### Task 3: Create Governance Proposal

**Quick Steps** (5 minutes)

```
1. Dashboard → "Governance"
2. Click "Create Proposal"
3. Title: e.g., "Increase lending APY to 15%"
4. Description: Explain why
5. Duration: 7 days (default)
6. Click "Create"
7. Share with community
8. ✓ Wait for voting period
9. ✓ Implement if approved
```

### Task 4: Check Portfolio Performance

**Quick Steps** (1-2 minutes)

```
1. Dashboard → "Portfolio"
2. View:
   - Total balance
   - Positions (loans, deposits)
   - Performance (gains/losses)
   - APY/interest earned
3. Click position for details
4. View transaction history
```

## 🔐 SECURITY BEST PRACTICES

### 1. Protect Your Keys ✓
- ✅ Never share private keys
- ✅ Use hardware wallets for large amounts
- ✅ Save backup seed phrase offline
- ✅ Store in secure location (safe, vault)

### 2. Strong Passwords ✓
- ✅ Use 12+ character passwords
- ✅ Mix uppercase, lowercase, numbers, symbols
- ✅ Don't use personal information
- ✅ Use unique password (not reused)

### 3. Enable MFA ✓
- ✅ Set up 2-factor authentication
- ✅ Use authenticator app (better than SMS)
- ✅ Save backup codes
- ✅ Never share codes with anyone

### 4. Verify URLs ✓
- ✅ Always check URL: https://stellaro.io
- ✅ Watch for phishing attempts
- ✅ Bookmark the official site
- ✅ Never click suspicious links

### 5. Test Small First ✓
- ✅ Start with small amounts
- ✅ Test transactions before large amounts
- ✅ Verify each step carefully
- ✅ Ask in community if unsure

## ❓ FREQUENTLY ASKED QUESTIONS

### Q1: How much does it cost to use Stellaro?

**A**: Only Stellar network fees (~0.00001 XLM per transaction, ~$0.000001)
- No platform fees
- No hidden charges
- No subscription
- Pure peer-to-peer finance

### Q2: Is my money safe?

**A**: Yes! Multiple security measures:
- Smart contracts audited
- Cryptocurrency secured
- Multi-signature governance
- Your wallet controls funds
- No Stellaro access to your keys
- Decentralized architecture

### Q3: What if I lose my password?

**A**: You can recover using:
- Email recovery link (check spam)
- Backup seed phrase (from wallet)
- Hardware wallet recovery
- Support team (ID verification required)

### Q4: How long do transactions take?

**A**: Stellar network is fast:
- Typical confirmation: 5-10 seconds
- Maximum: 30 seconds
- Much faster than Bitcoin/Ethereum

### Q5: What's the APY on lending?

**A**: Depends on pool and demand:
- Current: 5-12% APY (varies)
- Set by market (supply/demand)
- Higher risk = higher reward
- Check pool details for current rate

### Q6: Can I withdraw anytime?

**A**: Yes! Complete liquidity:
- Withdraw instantly (almost always)
- No lock-up periods
- No restrictions
- Funds arrive within minutes

### Q7: What is STLT-BRL?

**A**: Brazilian Real stablecoin:
- 1 STLT = 1 Brazilian Real (BRL)
- Fully collateralized
- Backed by actual reserves
- Perfect for Brazil/LatAm

### Q8: How do I report a bug?

**A**: Found an issue?
1. Visit: https://stellaro.io/support
2. Click "Report Bug"
3. Describe issue with screenshots
4. Our team investigates
5. Rewards for valid security issues

## 🐛 TROUBLESHOOTING

### Problem: Can't connect wallet

**Solution**:
1. Refresh browser (Ctrl+F5)
2. Check wallet extension is active
3. Try different browser
4. Reinstall wallet extension
5. Contact support

### Problem: Transaction stuck

**Solution**:
1. Check Stellar network status: https://stellar.org/status
2. Wait 30 minutes
3. Try again
4. If still stuck, contact support with transaction ID

### Problem: Low balance warning

**Solution**:
1. Buy more XLM on exchange
2. Withdraw to your Stellar address
3. Wait 5-10 minutes
4. Balance will update

### Problem: Can't withdraw funds

**Solution**:
1. Check minimum balance (2 XLM)
2. Verify withdrawal address
3. Check network status
4. Try again in 5 minutes
5. Contact support

### Problem: App loading slowly

**Solution**:
1. Refresh browser (Ctrl+F5)
2. Clear browser cache
3. Try incognito mode
4. Use different browser
5. Check internet speed
