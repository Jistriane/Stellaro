# Development Environment Setup

## Prerequisites

- Node.js LTS
- Python 3.10+
- Docker and Docker Compose (for optional local services)

## Quick Setup

1. Clone the repository:
   `git clone https://github.com/Jistriane/Stellaro.git`
2. Install root tooling and per-package dependencies.
3. Follow service-specific READMEs under `apps/`, `agents/`, and `contracts/` for local run instructions.

## Tests

Run package-local tests from each workspace (e.g., `npm test` in frontend, contract test commands in `contracts/`).
