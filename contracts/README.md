# Smart Contracts Workspace

## Overview

This workspace contains Stellaro's contract modules and supporting scripts.

## Contract Domains

- Governance and DAO controls
- Treasury and vault management
- Lending and risk management
- Stablecoin and payment mechanisms
- Verification and registry components

## Development Flow

1. Build contract modules.
2. Run unit and integration tests.
3. Validate deployment artifacts.
4. Execute network-specific deployment scripts.

## Safety Practices

- Enforce strict authorization checks
- Prefer explicit state transition validation
- Keep upgrade and migration procedures documented

## Deployment Notes

Mainnet/testnet deployments must use the correct network profile and passphrase mapping.
